# Remote File Access Project

This project allows you to connect to a remote machine via its IP address and access, browse, and download files from it. The backend is implemented in Python. A minimal CLI interface is provided for user interaction.

## Features
- Connect to a remote machine using its IP address
- List directories and files on the remote machine
- Download files from the remote machine

## Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Run the CLI: `python main.py`

## Requirements
- Python 3.8+
- The remote machine must have SSH enabled
